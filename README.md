# Playwright + Claude Code agent (JavaScript)

Claude drives a real browser through the Playwright MCP server to **plan → generate → run → self-heal** Playwright tests.
Two ways to use it: interactively inside Claude Code, or headless/dynamically from a Node script (CI-friendly).

## Prerequisites
- Node.js 20 LTS: `brew install node`
- Claude Code: `npm install -g @anthropic-ai/claude-code`
- An Anthropic API key for the headless runner

## Setup (macOS, zsh)
```bash
cd pw-claude-agent
npm install
npx playwright install chromium
npx playwright init-agents --loop=claude   # creates .claude/agents/* (planner, generator, healer) + .mcp.json
export ANTHROPIC_API_KEY="sk-ant-..."   # add to ~/.zshrc to persist
export BASE_URL="https://your-app.example.com"   # optional; defaults to the TodoMVC demo
```
Re-run `init-agents` whenever you upgrade Playwright.

If init-agents drops a `seed.spec.ts`, delete it and keep `tests/seed.spec.js`.

## Mode 1 — Interactive in Claude Code
```bash
claude
```
Then ask, e.g.:
- `Use the playwright-test-planner agent to plan tests for checkout. Seed: tests/seed.spec.js`
- `Use the playwright-test-generator agent to implement specs/checkout.md in JavaScript`
- `Use the playwright-test-healer agent to fix failing tests`

Check `/mcp` inside Claude Code shows `playwright-test` as connected.

Want plain free-form browsing too? Add the general browser MCP:
```bash
claude mcp add playwright -- npx @playwright/mcp@latest
```

## Mode 2 — Dynamic / headless runner
```bash
# Generate a suite from a plain-English goal
npm run agent -- --goal "User can add, complete, filter and clear todos" --name todos

# Against a different app
npm run agent -- --goal "Login with valid and invalid credentials" --url https://staging.myapp.com --name login

# Repair whatever is failing after a UI change
npm run agent:heal
```
The runner verifies with its own clean `playwright test` run and exits non-zero on failure, so it drops into CI directly.

## Files
| Path | Purpose |
|---|---|
| `CLAUDE.md` | Test conventions the agents follow (locators, assertions, JS-only) |
| `tests/seed.spec.js` | Starting context/style for generated tests — put login/setup here |
| `agent/run-agent.js` | Agent SDK runner: goal → plan → spec → run → heal → verify |
| `specs/` | Markdown plans written by the planner |
| `.claude/agents/`, `.mcp.json` | Generated by `init-agents` |

## Tips
- For authenticated apps, save a `storageState` once and reference it in `playwright.config.js` so the agent explores logged in.
- Review generated specs before committing — the healer marks real app bugs with `test.fixme()` instead of hiding them.
- Normal runs (`npm test`) don't call Claude at all; the agent is only for authoring and maintenance.
